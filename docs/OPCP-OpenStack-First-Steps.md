# OPCP OpenStack First Steps - Présentation pour les Clients

## Introduction

Bienvenue dans l'offre de découverte OpenStack de PSMC OVH. Ce programme vous permet de découvrir les fondamentaux de l'infrastructure Cloud OPCP OpenStack chez OVH dans un environnement sécurisé et pratique.

## Objectif de l'Offre

Cette formation vous permet de :
- Comprendre les concepts fondamentaux d'OpenStack
- Pratiquer l'utilisation des services principaux (Nova, Neutron, Cinder)
- Expérimenter la gestion des ressources cloud (instances, réseaux, stockage)
- Apprendre les bonnes pratiques d'authentification et de sécurité

## Public Cible et Profil

### Public Cible
- Administrateurs système souhaitant découvrir OpenStack
- Développeurs et ingénieurs IT intéressés par l'infrastructure cloud
- Professionnels souhaitant comprendre les bases de l'architecture cloud

### Profil Attendu
- Connaissance de base des concepts de cloud computing
- Capacité à utiliser un terminal/command line
- Familiarité avec les outils de développement de base

## Durée Estimée

### Temps Total : 1 journée
- **Phase 1 : Introduction et Prérequis** (~1 heure)
- **Phase 2 : Concepts Fondamentaux** (~1 heure)
- **Phase 3 : Exercices Pratiques** (~2 à 3 heures)
- **Phase 4 : Résumé et Prochaines Étapes** (~1 heure)

## Prérequis Techniques

Avant de commencer, assurez-vous de disposer des éléments suivants :

### Environnement Local
- **Python 3.9+** (recommandé : 3.11)
- **OpenStack CLI Client** (python-openstackclient)
- **Accès à un environnement OPCP/OpenStack**
- **Docker** (version 20.10 ou supérieure) - en option

### Outils Recommandés
- Terminal/Command Line (Linux/macOS/Windows WSL)
- Éditeur de texte (VS Code recommandé)
- (Optionnel) shai CLI (assistant IA terminal)

## Structure de l'Environnement de Formation

### 1. SkillHub - Formation Web Interactive
- Interface web multilingue (Français/English)
- Contenu structuré en modules pédagogiques
- Guide pas à pas pour chaque concept OpenStack
- Validation automatique des connaissances

### 2. Labs - Environnement de Pratique
- Connexion à un environnement OpenStack réel
- En option, containerisation complète avec Docker / environement simulé
- Exercices pratiques avec validation automatique
- Gestion sécurisée des ressources

## Modules de Formation

### Module 1 : Premiers Pas (First Steps)
- Création d'une instance (VM)
- Configuration réseau de base
- Création et attachement d'un volume

### Module 2 : Gestion des Compute (Nova)
- Lancement d'instances
- Redimensionnement de VM
- Gestion des snapshots

### Module 3 : Réseau (Neutron)
- Création de réseaux
- Configuration de sous-réseaux
- Configuration de routeurs

### Module 4 : Stockage (Cinder)
- Création de volumes
- Attachement de volumes
- Gestion des snapshots

### Module 5 : Configuration LACP
- Agrégation de liens
- Configuration de bonds
- Attachement à des instances
