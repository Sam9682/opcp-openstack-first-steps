Prérequis

Difficulté : Débutant · Durée estimée : 15 min

Avant de lancer les labs, assurez-vous que votre environnement remplit les conditions suivantes. Cette page détaille chaque dépendance et comment vérifier qu'elle est correctement installée.

Prérequis minimaux

Composant Version minimale
Python 3.9
OpenStack CLI 10.0.0
macOS Tahoe 26.5.2
Ubuntu 24 LTS

1. Environnement Bash

Tous les exercices nécessitent un environnement Bash. Vous pouvez utiliser :

  • Distributions GNU/Linux (Ubuntu, CentOS, Fedora, etc.)
  • macOS
  • Windows avec Windows Subsystem for Linux (WSL) et Ubuntu

Si vous utilisez Windows, installez WSL Ubuntu avec la commande suivante : 

wsl --install -d Ubuntu

Après l'installation, lancez Ubuntu depuis le menu Démarrer et terminez le processus d'installation.

2. Client CLI OpenStack

Tous les exercices utilisent le client en ligne de commande openstack. Installez-le via pip : 

sudo apt update && sudo apt install -y python3 python3-pip python3-venv
# Vérifiez la version de Python. Python 3.9+ minimum.
python3 --version
# Dans votre répertoire de travail, générez un nouveau venv Python puis activez le
python3 -m venv .venv
source .venv/bin/activate
# Installez openstack client CLI (incluant ironic client)
pip3 install python-openstackclient 
pip3 install python-ironicclient
# fermez votre session de terminal, puis retournez dans votre venv
exit
source .venv/bin/activate
# Vérifiez la présence des commandes Ironic (baremetal). La commande doit vous proposer des sous-commandes "baremetal"
openstack baremetal

3. Connaissances de base du terminal

Vous devez être à l'aise avec l'exécution de commandes dans un terminal (bash, zsh ou PowerShell). Tous les exercices se lancent en ligne de commande.

Script de validation rapide

Exécutez ces commandes pour vérifier que tout est en place :

# Vérifier la version de Python
python3 --version

# Vérifier que pip est disponible
pip3 --version

# Vérifier que le CLI OpenStack est installé
openstack --version
