Réseau

Difficulté : Intermédiaire · Durée estimée : 20 min

Les réseaux sont la base de tout déploiement cloud. Dans cette leçon, vous allez créer des réseaux virtuels, configurer des sous-réseaux avec validation CIDR et mettre en place des routeurs via l'API Neutron.

Objectif

Nous allons maintenant passer en revue les étapes pour configurer le réseau sur un nœud baremetal en utilisant le client CLI Openstack.

Créer un réseau privé et un sous-réseau

Étape 1 : Créer le réseau privé

Avant de déployer votre instance, il est généralement nécessaire de créer un réseau privé afin qu’il soit accessible au sein de votre infrastructure locale. Si vous avez déjà un réseau privé avec un subnet sur votre projet que vous souhaitez utiliser, vous pouvez ignorer l'étape de création et directement lister vos réseaux pour récupérer le nom ou l'ID du réseau concerné. 

openstack network create ${STUDENT_ID}-net

Par défaut, un réseau n’est visible que par le projet qui l’a créé (ainsi que par les utilisateurs administrateurs) et l'ID de segment est généré automatiquement.

Si vous souhaitez créer un réseau partagé entre tous vos projets, vous pouvez utiliser le paramètre --share.

Pour partager un réseau uniquement avec certains projets spécifiques, il est nécessaire d’utiliser le mécanisme Role-Based Access Control (RBAC) d’OpenStack : Documentation RBAC Neutron.

Par ailleurs, si vous souhaitez créer le réseau privé dans un VLAN particulier, vous pouvez le préciser à l’aide des paramètres suivants : 

--provider-network-type vlan
--provider-physical-network physnet1 # Valeur statique dans OPCP
--provider-segment $VLAN_ID # Segment-id de Neutron

Par exemple, si vous souhaitez créer un réseau privé partagé dans le VLAN 2050 nommé ${STUDENT_ID}-net : 

openstack network create --share --provider-network-type vlan --provider-physical-network physnet1 --provider-segment 2050 ${STUDENT_ID}-NET

Une fois le réseau créé, vous pouvez le lister via la commande : 

openstack network list --name ${STUDENT_ID}-net

Si nécessaire, vous pouvez lister l'ensemble des réseaux en retirant l'argument --name.

Étape 2 : Créer le sous-réseau

Par défaut, le seul élément nécessaire pour créer un sous-réseau sur votre réseau est le CIDR que vous souhaitez configurer et le réseau que vous venez de créer : 

openstack subnet create --network ${STUDENT_ID}-net --subnet-range 192.168.120.0/24 ${STUDENT_ID}-subnet

Si vous souhaitez cependant préciser un allocation pool, vous pouvez le spécifier via différents paramètres. Par exemple, si vous souhaitez créer un sous réseau avec le CIDR 192.168.120.0/24 en allouant uniquement 50 adresses IP du CIDR et avec une gateway spécifique, vous pouvez utiliser la commande suivante : 

openstack subnet create --network ${STUDENT_ID}-net --subnet-range 192.168.120.0/24 --allocation-pool start=192.168.120.11,end=192.168.120.60 --gateway 192.168.120.8 ${STUDENT_ID}-subnet

Ce sous-réseau pourra ensuite être utilisé pour déployer une instance, permettant ainsi à OpenStack d'attribuer une adresse IP à celle-ci lors de l'installation.

Résumé

  • Neutron gère le réseau OpenStack
  • Créez des réseaux avec openstack network create
  • Spécifiez l'ID de segment pour le réseau si nécessaire
  • Créez des sous-réseaux avec openstack subnet create
