Prerequisites

Difficulty: Beginner · Estimated time: 15 min

Before running the labs, make sure your environment meets the following requirements. This page walks you through each dependency and how to verify it is correctly installed.

1. Bash environment

All exercises require a Bash environment. You can use:

  • GNU/Linux distributions (Ubuntu, CentOS, Fedora, etc.)
  • macOS
  • Windows with Windows Subsystem for Linux (WSL) and Ubuntu

If you're using Windows, install WSL Ubuntu with the following command: 

wsl --install -d Ubuntu

After installation, launch Ubuntu from the Start menu and complete the setup process.

2. OpenStack CLI client

All exercises use the openstack command-line client. Install it via pip: 

sudo apt update && sudo apt install -y python3 python3-pip python3-venv
# Check python version. Python 3.9+ needed.
python3 --version
# Inside your working directory, generate a new python-venv then activate it
python3 -m venv .venv
source .venv/bin/activate
# Install openstack client CLI (including ironic client)
pip3 install python-openstackclient 
pip3 install python-ironicclient
# close your terminal session, then go back to your venv
exit
source .venv/bin/activate
# Verify the presence of Ironic commands (baremetal). It should offers to use "baremetal" sub-commands
openstack baremetal

3. shai CLI (optional — AI terminal assistant)

shai is an interactive coding agent that lives in your terminal. It can help you write code, fix bugs, and answer questions while working through the labs. 

# Check if shai is installed
shai --version

If shai is not installed, run the following command:

# Install the latest stable release
curl -fsSL https://raw.githubusercontent.com/ovh/shai/main/install.sh | sh

The binary will be installed in $HOME/.local/bin. Make sure this directory is in your PATH: 

# Add to your PATH if needed
export PATH="$HOME/.local/bin:$PATH"

4. Basic terminal knowledge

You should be comfortable running commands in a terminal (bash, zsh, or PowerShell). All exercises are launched from the command line.

Quick validation script

Run these commands to verify everything is in place:

# Check Python version
python3 --version

# Check pip is available
pip3 --version

# Check the OpenStack CLI is installed
openstack --version

# Test authentication
openstack token issue
