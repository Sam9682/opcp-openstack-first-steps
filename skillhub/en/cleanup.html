Cleanup Resources

Difficulty: Beginner · Estimated time: 10 min

Now that you have completed all the labs, it is time to clean up every OpenStack resource created during the exercises. All lab resources follow the naming convention ${STUDENT_ID}-*, which makes them easy to identify and delete.

1. Naming Convention

Every resource created throughout the labs is prefixed with your student_id. Here is the full list:

ModuleResource typeName pattern
NetworkingNetwork${STUDENT_ID}-net
NetworkingSubnet${STUDENT_ID}-subnet
ComputeInstance${STUDENT_ID}-compute-instance
LACPPort Group${STUDENT_ID}-pg-lacp
User ManagementProject${STUDENT_ID}-project
User ManagementKeycloak Client${STUDENT_ID}-cli

2. Deletion Order

OpenStack resources have dependencies. Deleting them in the wrong order will fail. The correct order is:

  1. Delete instances (Nova).
  2. Delete ports and port groups (Neutron).
  3. Delete subnets and networks (Neutron) — subnets are removed automatically.
  4. Delete client and user (Keycloak)
  5. Delete projects (Keystone) — note that users must be deleted first.

3. Manual Cleanup with the CLI

You can also clean up resources manually using the openstack CLI. Follow the deletion order above: 



# 1. Delete instances
openstack server delete ${STUDENT_ID}-compute-instance

# 2. Delete ports and port groups
# For LACP port groups (if created)
openstack baremetal port group delete ${STUDENT_ID}-pg-lacp

# 3. Delete subnets and networks
openstack subnet delete ${STUDENT_ID}-subnet
openstack network delete ${STUDENT_ID}-net

# 4. Delete client and user in Keycloak
Must be done through Keycloak UI

# 5. Delete projects (and users)
openstack project delete ${STUDENT_ID}-project

4. Verify Cleanup

After running the cleanup, verify that no resources remain by listing them with the OpenStack CLI: 

# List any remaining instances
openstack server list --name ${STUDENT_ID}-*

# List any remaining networks
openstack network list --name ${STUDENT_ID}-*

# List any remaining projects
openstack project list --name ${STUDENT_ID}-*

# List any remaining users
openstack user list --name ${STUDENT_ID}-*

If any resources remain, delete them manually using the openstack CLI or re-run the cleanup script.
