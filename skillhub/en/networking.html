Networking

Difficulty: Intermediate · Estimated time: 20 min

OpenStack networking is handled by the Neutron service. In this lesson you will create networks, subnets, and routers to connect your instances to the outside world or to each other.

Objective

We will now go through the steps to configure network on baremetal node using Openstack CLI client.

Create a private network and subnet

Step 1: Create the private network

Before deploying your instance, it is generally necessary to create a private network so that it is accessible within your local infrastructure. If you already have a private network with a subnet on your project that you want to use, you can skip the creation step and directly list your networks to retrieve the name or ID of the network concerned. 

openstack network create ${STUDENT_ID}-net

By default, a network is only visible to the project that created it (as well as administrators) and segment-id is auto-generated.

If you want to create a shared network across all your projects, you can use the --share parameter.

To share a network only with specific projects, you need to use OpenStack's Role-Based Access Control (RBAC) mechanism: Neutron RBAC Documentation.

Additionally, if you want to create the private network in a specific VLAN, you can specify it using the following parameters: 

--provider-network-type vlan
--provider-physical-network physnet1 # Static value in OPCP
--provider-segment $VLAN_ID # Neutron segment-id

For example, if you want to create a shared private network in VLAN 2050 named ${STUDENT_ID}-net: 

openstack network create --share --provider-network-type vlan --provider-physical-network physnet1 --provider-segment 2050 ${STUDENT_ID}-NET

Once the network is created, you can list it using the command: 

openstack network list --name ${STUDENT_ID}-net

If needed, you can list all networks by removing the --name argument.

Step 2: Create the subnet

By defat, the only element needed to create a subnet on your network is the CIDR you want to configure and the network you just created: 

openstack subnet create --network ${STUDENT_ID}-net --subnet-range 192.168.120.0/24 ${STUDENT_ID}-subnet

If you want to specify an allocation pool, you can do so with several parameters. For example, if you want to create a subnet with the CIDR 192.168.120.0/24, allocating only 50 IP addresses from the CIDR with a specific gateway, you can use the following command: 

openstack subnet create --network ${STUDENT_ID}-net --subnet-range 192.168.120.0/24 --allocation-pool start=192.168.120.11,end=192.168.120.60 --gateway 192.168.120.8 ${STUDENT_ID}-subnet

This subnet can then be used to deploy an instance, allowing OpenStack to assign an IP address to it during installation.

Summary

  • Neutron handles OpenStack networking
  • Create networks with openstack network create
  • Specify segment ID for network if needed
  • Create subnets with openstack subnet create
